التحديث v1.66.0 — مشروع الحفظ الخاص مُعد، والنشر اليدوي مطلوب

قاعدة البيانات الخاصة في Supabase جاهزة. نجحت اختبارات الصلاحيات والأمان، لكن الموقع المنشور لم يتغير لأن اتصال GitHub رفض الكتابة.

للنشر:
١. احتفظي بملف Full Backup الحالي قبل تحديث الموقع.
٢. فكي ضغط الملف.
٣. ارفعي الملفات التالية إلى جذر المستودع الحالي، مكان index.html الموجود:
index.html
service-worker.js
cloud-backup.js
cloud-config.js
لا ترفعي ZIP نفسه، ولا تنشئي مستودعًا أو رابطًا جديدًا. الأيقونات وmanifest الحاليان يبقيان كما هما.
٤. اضغطي Commit changes، وانتظري نجاح نشر GitHub Pages.
٥. أغلقي جميع نوافذ الموقع القديمة ثم افتحي نفس رابط موقعك. لا تمسحي بيانات الموقع أو المتصفح ولا تعيدي تثبيت التطبيق.
٦. تحققي من الإصدار v1.66.0. إذا بقي الإصدار القديم، حدّثي الصفحة مع وجود الإنترنت دون مسح التخزين.

تفعيل الحفظ:
١. اضغطي شريط الحفظ الخارجي أو افتحي حساب الموقع ثم الحفظ الخارجي — تسجيل الدخول.
٢. للمرة الأولى اختاري إنشاء حساب الحفظ. حساب لوحة Supabase منفصل عن حساب نسخ البحث داخل الموقع.
٣. أدخلي بريدك وكلمة مرور تختارينها لا تقل عن عشرة أحرف. لا ترسلي كلمات المرور أو روابط التفعيل في المحادثة.
٤. افتحي رسالة Supabase. يمكنك نسخ رابط التفعيل بالضغط مطولًا عليه ثم لصقه في خانة التفعيل داخل الموقع. هذه الطريقة تفعّل الحساب مباشرة دون الاعتماد على وجهة الرابط الافتراضية. إذا فتحتِ الرابط وفعّلتِ الحساب بالفعل، عودي إلى الموقع واختاري تسجيل الدخول.
٥. عند نجاح الدخول، يحاول الموقع حفظ أول نسخة من بيانات الهاتف الحالية. لا يستبدل البيانات الموجودة بقاعدة فارغة.
٦. لا تعتمدي على الحفظ الخارجي حتى يظهر آخر حفظ خارجي مؤكد مع التاريخ والوقت. إذا ظهر خطأ فهذا يعني أن النسخة الخارجية لم تُؤكد بعد؛ النسخة المحلية تبقى منفصلة.
٧. أرسلي فقط حالة الحفظ الظاهرة وعدد المرضى والزيارات للتحقق من أول حفظ. لا ترسلي كلمة المرور أو رابط التفعيل.

الحفظ المحلي يعمل دون إنترنت، والرفع يعمل بينما الموقع مفتوح ويعاد عند عودة الاتصال. النسخ الخارجية السابقة لا تُحذف أو تُستبدل عند الحفظ العادي. يوجد فحص سلامة للملفات ورفض لنسخة صفر مرضى أو صفر زيارات. إذا كانت القاعدة المحلية فارغة، يتحقق الموقع من نسخة خارجية سليمة قبل بدء قاعدة جديدة، ويقف عند تعذر التحقق.

لم تُرفع بيانات المرضى إلى الخدمة خلال الإعداد، ولم يتم اختبار الهاتف أو أول رفع بحسابك بعد. الخطة الحالية مجانية ذات حدود سعة؛ راقبي الاستخدام، ولا تُفعَّل ترقية مدفوعة تلقائيًا بواسطة هذا التحديث. المشروع المجاني قد يتوقف بعد أسبوع دون نشاط؛ يبقى الحفظ المحلي متاحًا.
